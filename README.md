### 🐢 [Gamera — Secure Password Generator](https://github.com/Prequelunsainted/Gamera-Secure-Password-Generator)
![Python](https://img.shields.io/badge/Python-306998?style=flat-square&logo=python&logoColor=white)
![CustomTkinter](https://img.shields.io/badge/CustomTkinter-8B5CF6?style=flat-square)
![JavaScript](https://img.shields.io/badge/PWA-JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

A **password and passphrase generator** using cryptographically secure randomness (`secrets`), with a modern Kaiju-themed UI and a PWA version.

- Strength meter with entropy in bits and estimated time to crack
- Fine-grained character control, avoids ambiguous characters and clears the clipboard after 30 seconds
- In-memory history only: **passwords are never saved**
- Windows executable (`Gamera.exe`), terminal mode, automated tests and CI
